# Sign-up Form

A sign-up form project from [The Odin Project](https://www.theodinproject.com/lessons/node-path-intermediate-html-and-css-sign-up-form).

## About

This project is part of The Odin Project's Intermediate HTML and CSS course.

For the first version, I will follow the assignment requirements as closely as possible instead of adding features or techniques that haven't been covered yet.

The goal is not only to practice HTML forms, CSS, and form validation, but also to get used to building a project according to a given specification — similar to working with requirements from a future client.

## Current Goals

- Build the page according to the provided design
- Practice semantic HTML forms
- Use proper labels and form controls
- Apply built-in HTML validation
- Style validation and focus states with CSS
- Keep the implementation within the current scope of The Odin Project curriculum

## Future

After learning more advanced CSS, responsive design, JavaScript, and form validation techniques, I may return to this project and create a second version using the additional knowledge I've gained.

For now, the priority is to complete the project according to the original assignment requirements.
