# Sign-up Form

A sign-up form project from [The Odin Project](https://www.theodinproject.com/lessons/node-path-intermediate-html-and-css-sign-up-form).

## About

This project was built as part of The Odin Project's Intermediate HTML and CSS course.

For this version, I intentionally followed the assignment requirements closely instead of adding features or techniques that were outside the current scope of the curriculum.

The goal was not only to practice HTML forms, CSS, and form validation, but also to get used to building a project according to a given specification — similar to working with requirements from a future client.

## Features

- Two-column page layout
- Responsive image sizing with `object-fit`
- Custom Odin logo banner
- Local custom font using `@font-face`
- Structured sign-up form with labels and form controls
- Built-in HTML validation
- Email and password field validation
- Focus states for form inputs
- Invalid input styling using `:user-invalid`
- Form section and button styling
- Image attribution

## Technologies

- HTML5
- CSS3
- Flexbox
- HTML Constraint Validation
- Custom fonts

## What I Practiced

This project helped me practice:

- Structuring forms with proper labels and inputs
- Connecting `label` elements to form controls using `for` and `id`
- Working with `required`, `type`, and `minlength`
- Styling form validation states
- Using Flexbox for page and form layouts
- Positioning elements over images with `position: relative` and `absolute`
- Working with relative CSS units such as `%`, `vw`, `rem`, and `em`
- Using `object-fit: cover` for responsive images
- Loading local fonts with `@font-face`

## Future

After learning more advanced CSS, responsive design, and JavaScript form validation, I may return to this project and build a second version.

Possible future improvements include:

- Mobile and tablet layouts
- JavaScript password confirmation validation
- More advanced validation feedback
- Improved accessibility
- Additional responsive typography

For this version, the priority was to stay within the original assignment requirements.
